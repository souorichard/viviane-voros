# viviane.voros — Landing Page

Landing page desenvolvida para Viviane Voros, professora de Inglês Geral e Business English, com foco em apresentar sua metodologia, experiência e converter visitantes em contato via WhatsApp.

## Sobre o projeto

Site institucional de página única (one-page), construído com foco em transmitir profissionalismo e sofisticação através de um design editorial em preto, branco e beige. O projeto foi pensado para ser leve, rápido e fácil de manter, sem depender de backend ou banco de dados.

## Tecnologias

- **Next.js** (App Router) — framework React com renderização otimizada
- **TypeScript** — tipagem estática em todo o projeto
- **Tailwind CSS** — estilização utilitária
- **shadcn/ui** — componentes acessíveis e customizáveis
- **Framer Motion** — animações de entrada e interações de scroll
- **Biome** — linting e formatação de código

## Funcionalidades

- Design responsivo, adaptado para mobile, tablet e desktop
- Header com efeito de fundo dinâmico ao rolar a página
- Indicador de seções fixo, com destaque da seção ativa durante o scroll
- Botão de "voltar ao topo" com exibição condicional próximo ao fim da página
- Integração direta com WhatsApp (link com mensagem pré-preenchida)
- Animações de entrada suaves (fade-in) ativadas conforme o scroll
- Seções: Início, Sobre, Metodologia, Business English, Depoimentos e Contato

## Estrutura de seções

1. **Hero** — apresentação principal com call-to-action para WhatsApp
2. **Sobre** — experiência profissional e abordagem de ensino
3. **Metodologia** — diferenciais pedagógicos (aulas personalizadas, Task-Based Approach, formação acadêmica)
4. **Business English** — treinamentos corporativos customizados
5. **Depoimentos** — avaliações de alunos e empresas atendidas
6. **Contato** — reforço do propósito e novo call-to-action

## Rodando localmente

```bash
# Clonar o repositório
git clone https://github.com/[seu-usuario]/viviane-voros-landing.git

# Instalar dependências
npm install

# Rodar em ambiente de desenvolvimento
npm run dev
```

Acesse `http://localhost:3000` no navegador.
